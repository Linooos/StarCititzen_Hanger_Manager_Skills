# 星际公民 CCU 升级链规则

> 原文规则，作为后续功能开发的依据。可随时修改完善。

## 1. 基本概念

### 1.1 升级包 (Upgrades / CCU)

- 升级包是在机库中船只项目（Standalone Ships）上应用的，用于升级到价格更贵的船只。
- 升级包可以不断叠加，以追求更高价值的船只。
- 升级包具有 `from`（原始船只）和 `to`（升级后船只）属性。
- 升级包并非以实际价值计算，部署时只能应用到机库内已有的对应原始船只（from 船），不能应用到同价值的其他船只。

### 1.2 Warbond CCU

- Warbond CCU 代表官方打折获取的升级包。
- **实际价值**：玩家实际消费的金额（现实货币）。
- **价值**：原船只升级到目标船只价格间的差额。
- 两者可能不对等（打折导致实际价值低于标称价值）。

### 1.3 种子船 (Seed Ship)

- 船只（Standalone Ships）拥有附加属性：当前具体船只、保险信息、附赠物品、游戏资格等。
- 种子船是整个升级链条的基础、起点。
- 永久保险（LTI）的种子船价值最高。

### 1.4 溶解 (Exchange / Melt)

- 机库内项目可以被溶解（exchange），返还玩家花费的实际价值等额的信用点数（Store Credit）。
- 信用点数可作为代金券在商店（Pledge Store）消费，但无法购买打折商品（通常带 Warbond 词条）。
- 被溶解的项目从机库中消失。

### 1.5 升级包部署

- 升级包只能对对应的原始船只（from 船）进行升级。
- 升级包附带的其他属性或物品并入原始船只的附带物品（如皮肤、保险等）。
- 升级包的部署不可逆（除非溶解整个升级后的船只包）。

## 2. 保险规则

- 船只保险不能通过升级包携带的保险进行不断叠加。
- 保险取最高值：如船只中同时携带 120 月保险和永久保险（LTI），则取永久保险（LTI）为最终保险。
- 保险等级从低到高（大致）：3mo < 6mo < 12mo < 24mo < 120mo < LTI（永久）

## 3. 升级后船只属性

- 如船只（Standalone Ships）具有 `upgrades` 缩进栏（`js-upgrade-log upgrade`），意味着该船只已经应用过其他升级包。
- 应用升级包后，原始标签显示的是原船名，实际代表的是升级后的新船只。
- 叠加升级包后，最终船只价值为**最后部署的升级包的"升级后船只"的价值**。

## 4. 价值计算

### 4.1 实际价值计算

```
船只实际价值 = 种子船(Standalone Ship)实际价值 + 升级包1实际价值 + 升级包2实际价值 + ...
```

### 4.2 最终船只价值

```
最终船只价值 = 最后一个升级包的目标船(升级后船只)的价值（商店标价）
```

### 4.3 升级效率

```
升值率 = 最终船只价值 / 实际总价值
节省金额 = 最终船只价值 - 实际总价值
```

## 5. CCU 链条优化目标

用更少的实际价值（玩家的现实货币）获取价值更高的船只。

即：在所有可能的升级包组合中，找出实际总价值最低但最终船只价值最高的路径。

## 6. 爬取数据要求

为支持 CCU 计算，需从机库页面爬取以下额外信息：

### 6.1 Standalone Ships 附加信息
- 附带物品列表（皮肤、装备、 flair 等）
- 保险信息（类型、时长）
- 当前实际船只名称（展开 details 后的实际船名，非标签显示名）
- 游戏资格（星战公民下载权限、42中队权限等）
- 已应用的升级包列表（`js-upgrade-log` 缩进内容）

### 6.2 Upgrades 附加信息
- 原始船只（from ship）：名称 + 商店价值
- 升级后船只（to ship）：名称 + 商店价值
- Warbond 状态：实际价值 vs 标称差额
- 是否可溶解（not buybackable）

### 6.3 通用信息
- 机库项目的实际溶解价值（exchange value / melt value）
- 项目赠送/活动来源标记
